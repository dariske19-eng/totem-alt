# Totem Alt

Client-side Fabric mod for Minecraft 1.21.

**Fitur:**
- Tekan **Left Alt** (bisa diganti di Controls → Key Binds)
- Kalau ada Totem of Undying di inventory atau hotbar → otomatis dipindah ke tangan kiri (offhand)
- Hanya bekerja jika ada totem
- Fully client-side

## Cara Install
1. Install Fabric Loader untuk Minecraft 1.21
2. Install Fabric API untuk 1.21
3. Masukkan file `totem-alt-1.0.0.jar` ke folder `mods`
4. Mainkan!

## Build Sendiri
```bash
./gradlew build
```
Hasilnya ada di `build/libs/totem-alt-1.0.0.jar`
